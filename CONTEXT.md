# GenshinFlex

Гайд-сайт по Genshin Impact: билды персонажей, эндгейм, баннеры и инструменты для игроков на трёх языках.

## Language

### Гайды

**Билд**:
Рекомендация по сборке одного персонажа: оружие, артефакты, характеристики, команды и текст разбора.
_Avoid_: гайд персонажа (гайд — это текст билда целиком вместе с разбором)

**Ротация билда**:
Последовательность действий персонажа и союзников в бою, записанная шагами (E → Q → M1-M2-M3).
_Avoid_: ротация (без уточнения), комбо

### Игрок

**UID**:
Номер игрового аккаунта Genshin Impact (9–10 цифр). У одного человека может быть несколько UID.
_Avoid_: ID игрока, номер аккаунта

**UID профиля**:
UID, который пользователь показывает в своём профиле; инструменты подставляют его по умолчанию, но могут помнить свой выбор.

**Мои персонажи**:
Персонажи, которые есть у пользователя в игре, с их прокачкой.
_Avoid_: ростер, коллекция

### Время

**Регион**:
Игровой сервер, к которому привязан аккаунт: Европа, Америка или Азия. Определяет, когда для игрока начинаются и заканчиваются события.
_Avoid_: сервер (без уточнения), часовой пояс

**Время сервера**:
Время начала и конца игровых событий в конкретном регионе. Даты событий на сайте записываются по времени европейского сервера и пересчитываются под регион игрока.
_Avoid_: местное время, UTC

### Эндгейм

**Ротация**:
Сезон эндгейма с фиксированными сроками: цикл Бездны, Театра воображариума или Натиска со своими врагами, баффами и составами.
_Avoid_: цикл эндгейма, ротация Бездны (синонимы — допустимы в тексте сайта, но в коде и обсуждении — «ротация»)
