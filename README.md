# GenshinFlex

Открытый справочник по Genshin Impact: билды, команды и рейтинг персонажей под **текущую** ротацию
Витой бездны, Театра воображариума и Натиска — всё на одной странице. Без рекламы.

## Что внутри

- **Главная** — поиск с вкладками «Недавние / Избранное / Результаты», текущий баннер и таймеры до обновления Бездны, Театра и Натиска.
- **База** — персонажи (статы на любом уровне, множители талантов, созвездия), оружие (статы, пробуждения R1–R5), артефакты. Данные — [genshin-db](https://github.com/theBowja/genshin-db), картинки — enka.network.
- **Руководства** — билды и команды в Markdown (`src/content/builds`), проверяются схемой при сборке.
- **Ротация** — текущие циклы эндгейма (`src/content/rotations`), **баннеры** — `src/content/banners`, таймеры по времени выбранного сервера.
- **Конструктор ротаций** — команда, оружие, сеты и порядок действий; всё состояние хранится в ссылке.
- **Рейтинг** — вместо тир-листа два независимых рейтинга на Glicko-2: *по мнению сообщества* и *по забегам*. В разработке.
- **Поиск** — мгновенный по названиям плюс полнотекстовый по гайдам на [Pagefind](https://pagefind.app).

## Запуск

```sh
npm install
npm run import   # обновить данные игры в src/data/generated
npm run dev      # dev-сервер (поиск работает только после сборки)
npm run build    # сборка + поисковый индекс
npm run preview
```

## Планы

1. Заполнение билдов и текущих ротаций
2. ELO сообщества: попарное голосование (Cloudflare Worker + D1)
3. ELO по забегам: форма сабмитов
4. ИИ-помощник, отвечающий со ссылками на страницы сайта
