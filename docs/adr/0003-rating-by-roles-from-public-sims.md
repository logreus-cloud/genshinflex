# Рейтинг по ролям из открытых симуляций вместо ELO

Сообщества пока мало, поэтому ELO (попарные голоса и забеги) не наберёт матчей. Рейтинг строится из открытых расчётов урона: внутри каждой роли персонажи ранжируются по своей метрике, а в категориях эндгейма ранжируются команды. Роли между собой не сравниваются. ELO/Glicko-2 остаётся будущим третьим слоем. Карта — #62, методика — #63.

## Источники

1. **База симуляций KQM (gcsim)** — основной источник чисел. `https://db.kqm.gg/api/db?q=<json>` (Mongo-подобный запрос: `query`, `sort`, `project`, `skip`, `limit`; нужен заголовок `User-Agent`). На 27.10.2026 в ней 6020 проверенных симуляций (июль 2023 — сентябрь 2026), из них 5200 с 5★ персонажами на C0. Сводка записи (`summary`) даёт состав, созвездия, оружие с пробуждением, урон команды в секунду на цель и число целей. Полный результат по `share_key`: `https://gcsim.app/api/share/<share_key>`. Там для каждого персонажа есть урон в секунду (`statistics.character_dps`), лечение (`hps`), щиты (`shp`) и время на поле (`field_time`). Сами расчёты сделаны по стандартам KQM: уровень 90, таланты 9/9/9, 40 доп. статов на 5★ артефактах (20 фиксированных + 20 распределённых), враг 100 уровня с 10% сопротивлений, не меньше 90 с боя и 1000 итераций.
2. **Симулятор gcsim** (AGPL-3.0, открытый код): конфиги из базы можно перезапустить с нашей базой (C0, другое оружие). Это способ досчитать то, чего нет в базе, в том числе вклад поддержки (см. ниже). Новейших персонажей 7.x в gcsim пока нет: на 27.10.2026 не реализованы Весна, Водяница, Сандроне, Линнея, Лохен, Нефер.
3. **Тир-листы и гайды** (Game8 и остальные из `reference`-списка источников гайдов): для персонажей, которых нет в gcsim, и для проверки здравого смысла. Цифр урона у них обычно нет, поэтому оценка таких персонажей помечается как экспертная, а не расчётная.
4. **YouTube-каналы с максимальным уроном**: обычно это C6R5 и идеальные артефакты, поэтому для базы они не годятся. Используются для вариантов с созвездиями и сигнатурным оружием (этап 2, #69).

## База сравнения

- 5★ персонажи — C0, 5★ оружие — R1.
- 4★ персонажи — C6, 4★ оружие — R5: их созвездия и пробуждения доступны без доната. Если требовать C0 и от них, в базе остаётся 810 симуляций из 6020, и почти пропадают Беннет, Сян Лин, Син Цю, Фишль и другие 4★ поддержки.
- Остальное по стандартам KQM (выше). Отклонение от базы помечается на записи.

## Роли и метрики

| Роль | Метрика | Откуда |
|---|---|---|
| Керри | урон в секунду персонажа в его лучшей команде | `character_dps` |
| Саб-DPS | урон в секунду вне поля, включая реакции, которые он запускает | `character_dps` + `field_time` |
| Поддержка | прирост урона команды: урон с ним минус урон с эталонной заменой, в % | перезапуск конфига с заменой; без перезапуска — из процентов баффа в описании таланта, помечается как оценка |
| Сустейн | лечение и щиты в секунду (`hps`, `shp`) | порог: «не хватает / хватает / с запасом» |

- Overall — лучшие внутри каждой роли, по лучшей команде персонажа.
- Режимы (Бездна, Театр, позже Натиск и группы боссов) ранжируют команды. Команда помечена реакцией или архетипом, урон берётся с поправкой на цикл: число целей, элементы врагов, щиты.
- Внутри категории оценка 0–100 (лучший = 100, линейно по метрике), тиры S/A/B/C — подписи к диапазонам.

## Реализация (27.10.2026)

- Данные не в Sanity: `npm run rating:data` (`scripts/rating-data.mjs`) пишет `src/data/rating.json`, как `investments.json`; экспертные оценки и сустейн — в `src/data/rating-manual.json` в git. Расчёт — `src/lib/rating/core.ts` с тестами.
- В базе KQM поля по умолчанию не пишутся: нет `cons` — C0, нет `refine` — R1. Созвездия путешественника бесплатны, поэтому для него, как для 4★, любые.
- Роли в команде: керри — наибольшая доля урона (≥35%) и не меньше 30% времени на поле; саб-DPS — доля ≥12%; остальные — поддержка. Условие на время на поле нужно, потому что gcsim записывает урон цветения и вегетации тому, кто запустил реакцию (иначе Син Цю попадает в керри). Роль засчитывается персонажу, если он играет её хотя бы в 30% своих симуляций.
- Метрика роли — среднее двух лучших значений, чтобы один выброс не делал персонажа первым. Поддержка пока оценивается по урону своих лучших команд, а не по приросту от замены: прирост требует перезапуска gcsim и остаётся улучшением на потом.
- Экспертная оценка по тир-листам: SS — 92, S — 82, A — 72, B — 60 (в карточке подписано). Сустейн: «с запасом» — 90, «хватает» — 75, «мало» — 55.
- Известное ограничение: команды цикла ранжируются по урону по одной цели, без поправки на число врагов и щиты.

## Considered Options

- **Свой калькулятор урона** отклонён: множители, ротации и баффы для 127 персонажей — отдельный проект, а gcsim уже всё это делает и открыт.
- **Строгое C0 для всех** отклонено: см. «База сравнения».
- **Копировать чужие тир-листы** отклонено: берём числа и ссылаемся на источник, таблицы не переносим.

## Consequences

- В каждой записи рейтинга хранятся источник (ссылка на симуляцию или статью), патч и признак «расчёт / экспертная оценка».
- Данные из базы KQM не зеркалируем целиком: храним только нужные метрики и ссылку на симуляцию.
- Персонажи без симуляций получают экспертную оценку до появления их в gcsim.
