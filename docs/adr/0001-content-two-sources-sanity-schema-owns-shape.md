# Два источника контента, форма — за схемой Sanity

Контент живёт одновременно в md/JSON (`src/content`, правки через ИИ и git) и в Sanity (правки вручную в Studio), шов между ними — `scripts/cms/store.mjs`; ни один источник не отменяется. Форму каждого типа контента задаёт схема Sanity в `apps/studio/schemas`: карта коллекций, объектные типы, локализуемые пути, порядок полей, сериализатор md и сбор строк для перевода выводятся из неё, а zod-схема сайта остаётся рукописной и сверяется с ней контрактным тестом.

## Considered Options

- Нейтральное описание, из которого генерируются и zod, и Sanity — отклонено: пришлось бы заново описывать возможности Studio (заголовки, `hidden`, валидация).
- Оставить копии формы и только ловить расхождения тестом — отклонено: копии продолжают требовать ручной синхронизации (поле `rotations` потерялось в четырёх из девяти мест).
- Оставить один источник (только Sanity или только md) — отклонено: md удобен для пакетных правок ИИ, Studio — для ручных.
