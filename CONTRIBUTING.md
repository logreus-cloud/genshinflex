# Как добавить билд

1. Создайте `src/content/builds/<слаг-персонажа>.md` — посмотрите `raiden-shogun.md` как пример.
2. Слаги персонажей, оружия и артефактов берутся из `src/data/generated/*.json` (английское имя в kebab-case).
   Опечатка в слаге роняет сборку — так ошибки не попадают на сайт.
3. Пишите своими словами. Не копируйте тексты с других сайтов; если опирались на чужой гайд — укажите его в `sources`.
4. `npm run build` должен проходить без ошибок.

# Как обновить ротацию

Отредактируйте `src/content/rotations/<режим>-current.json`, заполните `stages`, `buffs`, `teams` и уберите `"draft": true`.

# Как опубликовать новость сайта

1. Добавьте Markdown-файл в `src/content/news/ru/` и переводы с тем же именем в `en/` и `es/`. Пример — `launch.md`.
2. Заполните `lang`, `anchor`, `title`, `summary` и `date` (`YYYY-MM-DD`, при необходимости со временем в ISO 8601). `anchor` должен быть уникальным в пределах языка и одинаковым у всех переводов. После публикации его не меняйте: это постоянная ссылка на запись.
3. Используйте заголовки третьего уровня (`###`) и ссылки с префиксом языка в переводах (`/en/`, `/es/`). Для неопубликованных записей задайте `draft: true`.
4. Записи выводятся на `/news/` от новых к старым. Баннер главной автоматически берёт заголовок и описание последней опубликованной записи и ведёт на `/news/#anchor`. Будущая дата сама по себе не скрывает запись — для этого используйте `draft`.
5. Запустите `npm run build` перед публикацией.
